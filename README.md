# nieuwsbrief-beelden

Afbeeldingen voor de nieuwsbrieven van Tycho (trendradar en X-overzicht), via GitHub Pages:
`https://tychoml.github.io/nieuwsbrief-beelden/<nieuwsbrief>/<datum>/<bestand>.jpg`

Mappen per nieuwsbrief en datum, bv. `trendradar/2026-10-08/hero.jpg`. Alleen AI-gegenereerde illustraties, geen persoonsgegevens.
Bijgewerkt door `/workspace/mail_tools/host-images-gh.js`.
